## Section 1 – Why TypeScript

### Task 1
- Demonstrated a runtime error in JavaScript by calling a function with an invalid argument.
- Rewrote the same function in TypeScript using a `string` parameter type.
- Verified that TypeScript caught the error at compile time.

### Task 2
- Used the TypeScript Playground.
- Observed the error:
  - `Type 'number' is not assignable to type 'string'.`
- Understood that the returned value must match the declared return type.

### Task 3
Explored three open-source TypeScript projects:

- React – UI Library
- VS Code – Code Editor
- Angular – Frontend Framework

Learned that TypeScript is widely adopted because it improves maintainability, refactoring, IDE support, and compile-time safety.
